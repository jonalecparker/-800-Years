# Session — 2026-07-21

## Goal

Kick off design for game two (medieval castle lord) and set up this repo/workspace.

## What we did

- Established the design workflow: user narrates stream-of-consciousness, Claude organizes into `medieval-castle-lord.md` (core fantasy, core loop, pillars, one thing, scope guardrails, idea dump, open questions).
- Wrote and iterated the design doc through four narration rounds. Major decisions landed:
  - **First-person is the game**; top-down management view is subordinate (cut first under scope pressure).
  - **Walk-around Europe stays in** — big lift acknowledged; goal is the *impression* of Europe, not 1:1.
  - **Progression = ambition ladder** (money / armies / alliances as three routes up), not survival pressure.
  - **Pillar 5: "A noble acts through people"** — no personal skill grind; the best gear comes from hiring the best blacksmith. Money is the universal currency of power.
  - **Vassals & economy:** farmers (choose crops/livestock) as mercantile foundation; specialists (blacksmith, stable master, steward); housing loop.
  - **Steward:** competence tiers priced to match; can mismanage; can rebel and seize the estate if you're absent too long or renown too low → introduced the **renown** stat (undesigned).
  - **First-person content model:** castle-walking is mostly ambient; real content concentrated in a few castle NPCs (blacksmith → gear/army equipment; head builder → castle upgrades + castle-local terrain shaping). No content on farms.
  - **Historical grounding:** reference year c. 1220; manorial bargain documented (protection, justice, custom, commons, famine relief; failure state = workers leave for better lords).
  - **Alliances tabled** by choice; lean is one-time single-goal arrangements.
- Set up this folder as the game-two workspace: git repo initialized and connected to `github.com/jonalecparker/-800-Years`, Unity-ready `.gitignore`, `Docs/` scaffolding, and adapted `/start` and `/wrap` commands from game one for the design phase (Unity save step now skips gracefully when no Unity project exists).
