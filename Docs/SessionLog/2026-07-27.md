# Session — 2026-07-26 → 2026-07-27

## Goal

A check-in on the building system that became the biggest architecture session yet. The user articulated the vision precisely: **complete freedom in how a castle looks, limited only by physics** — the grid was meant as an aid, not a substrate, and wall connections should be real things, not "walls buried inside other walls." We agreed on a four-step plan (unify the two wall systems → model connections → cut junction geometry properly → structural support on top) and executed steps 1–3 — then, on the user's call mid-session, went further: killed the grid entirely and replaced it with an assist toolkit.

## What we did

- **Step 1 — Unification** (`GridPlacementSystem.cs` rewritten, `PlacedPiece.cs` deleted): every wall is a `SplineWall` now — the straight tool keeps its press-drag-release feel but commits a bulge-0 spline; a plain click commits a token 10cm chord the end extensions grow into a stub. Per-cell placement, assist trigger boxes, column/group/line delete logic all deleted; the delete tool is spline-only (wall-section ranges). Free wins: world-anchored UVs on straight walls (killed the texture-stretch backlog item), course stacking works on every wall, and the 25° rule collapsed to one implementation.
- **Step 2 — Connection model** (`SplineWall.Links`): a stored, bidirectional set of every wall this wall physically meets, resolved at commit by expanded-box overlap (flush contact, T-joints, and stacked courses all count). The delete tool snapshots the neighborhood before destroying (`DestroyImmediate` so probes see cleared space), then survivors `RebuildSections()` + `ResolveLinks()`: buried stubs retract, junction gaps regrow solid when their host dies. Stacked courses (`isStackedCourse`) and walls with delete holes (`hasGaps`) never rebuild — a rebuild would drop a course to the terrain or resurrect the holes.
- **Step 3 — Junction cut geometry**: interpenetration replaced by cuts. `FindJunctionBands` scans the sweep for intervals where the centerline sits inside an *older* wall's body (one band **per host wall** — they overlap at multi-wall junctions); sections inside are dropped, and every kept piece carries the applicable hosts' **face planes** (`cutPoints`/`cutNormals`, inset 1.5cm into the host against z-fighting). Mesh rows clip their cross-section per plane (`ClipRow`) so cut edges follow host faces exactly — flush butt caps at 90°, clean diagonals at 15°. Cutting is asymmetric and stable via `buildOrder` (newer cuts against older, never the reverse). `SideCrossing` sizes its search from the actual face-vs-tangent angle.
- **Gap rule per user spec**: strictly-under-one-unit face gaps connect (probe reach 1.25 + 0.2 radius ⇒ faces < 1.45m from the endpoint); a gap of exactly 1m is preserved as a deliberate separator. Junction angle threshold lowered 25° → 10° — reframed as the duplicate/lateral-overlap discriminator, not an aesthetic gate.
- **The grid is gone** (user decision): `SnapToGrid` deleted, `GridVisualizer` removed from the scene and deleted, placement is free. Alignment via assists: endpoint chaining (unchanged), drag **length** stepping 0.5m *relative to the anchor* (direction fully freeform after user feedback — Shift snaps to 15°, Alt frees everything), flank targeting (continuous, lands the centerline flush against a pointed-at face). `gridSize` survives only as wall thickness / target section length.
- **Distance guides** (two iterations): first one line per free endpoint to the nearest wall ≤5m; then per user spec, the 10m square around the ghost splits into four sectors from its corners (ahead/behind/left/right of the run, sector boundaries rotate with the wall) — one line + IMGUI distance label per sector, max four.
- **Offset tool** (`BuildMenu` button + `SplineWall.OffsetCurve`): click a wall → parallel copy previews at a locked distance; plain scroll steps the distance 0.5m (wheel claimed via `ClaimingScrollWheel`, now four-way arbitrated), cursor side picks the side, click commits a normal wall (own terrain stepping, own junction cuts). Offset math exact for straight walls, ≤2cm error on a heavily bulged one.
- **Refused placement shows red, never vanishes**: previews build with `includeBlocked: true`; duplicate-blocked pieces carry `SectionSpec.blocked`, tint red (`SetGhostTint`), don't count in the HUD, and `SplineWall.Create` skips + disposes them — so a half-overlapping drag shows red over the overlap, blue beyond it, and lays only the blue.
- **Graze lanes**: side-offset scans (angle-free — a same-face graze necessarily passes through a parallel-to-host moment) catch what the centerline misses: a curved face dipping into a host mid-run, and a wall **leaning alongside** another — which now **fuses flush** against the older wall's face instead of interpenetrating (face plane found by sideways raycast from the centerline; `IsBlocked` correspondingly slimmed to refuse only centerline-reach). Chained-corner overshoot **crumbs** (pieces severed from the wall body by a band) are dropped.
- Everything above verified programmatically in play mode each round: crossings at 90°/45°/15°, triple junctions, T-joins at 0/1-unit gaps, duplicates (exact + half-overlap), leans, grazes, chained corners, host-delete retraction/regrowth, course cut propagation, free-coordinate placement, offset distances, blocked-spec commits.

## Decisions & trade-offs

- **Model before mesh.** The check-in's key argument: the physics vision ("can't stack a hundred unsupported stones") *requires* a connection graph — interpenetrated meshes can't answer "is this supported?" So `Links` landed before any junction geometry, and it paid off immediately (retraction/regrowth on delete).
- **Unify before junctions** so junction work is built once, not twice.
- **"Older wall wins" (`buildOrder`)** makes cutting asymmetric and stable — rebuilds can't eat a hole from both sides of a crossing.
- **Row clipping over per-side trim parameters.** At shallow angles a host face crosses the wall diagonally over multiple sections (half-width ÷ tan θ per side); only clipping each swept cross-section row against the plane represents that. Cut planes attach liberally (clipping no-ops where a plane doesn't touch).
- **10° floor stays** — below it there's no sane joint geometry and "crossing" is indistinguishable from a misplaced parallel; everything above it cuts cleanly.
- **Lean = fuse, not refuse.** Only a wall whose *centerline* reaches another's body is a duplicate; face-deep leaning clips flush. Fits the freedom vision directly.
- **Relative stepping over world snapping**: lengths quantize from the anchor, keeping strokes commensurable (the project's stepped-increments philosophy) without constraining where anything starts.
- **Offset tool as a bar mode** (not a modifier gesture) because the scroll wheel was already three-way arbitrated.

## Dead ends

- **Per-side trim parameters** (`tStartOuter`…): correct at steep angles, structurally unable to represent the shallow-angle diagonal; replaced by cut-plane row clipping the same session.
- **Single merged junction band** with one entry/exit plane: leaked geometry at triple junctions (second host's face never clipped); replaced by per-host bands with plane lists.
- **Angle-filtered graze lanes**: gutted themselves (see above); the filter was removed for grazes only.
- **Transition-based graze plane resolution**: a wall leaning alongside a host for its whole length never transitions in/out, so no plane was ever found; replaced by the sideways raycast.
- **15° direction snap as the default**: shipped, then demoted to Shift-opt-in on user feedback the next message.

## Bugs hit

- **Borderline face raycasts**: the 0.05-radius inside-probe fired while the centerline was still outside the host, so the face raycast started from a sample that never entered and missed the plane by float luck (one test passed, its twin failed at 0.10m short). Fix: near-point probes (0.01) + generous raycast overshoot — the first host hit is the near face regardless.
- **Triple-junction leak** (98 stray verts) and **shallow-angle leak** (pieces sections away from the band poking in) — both architectural, both fixed as above.
- **Corner crumbs**: chained-corner overshoot left a 0.2m nub on the far side of the host; fixed by the orphan rule (piece entirely past an endpoint + severed by a band → dropped).
- **Test-layout self-collisions, repeatedly**: test walls crossing *each other* (not the intended host) produced three separate false alarms — a 15° wall crossing the 90° wall, a "retraction" wall legitimately connecting to a third wall, a regrow-check excluding the checked wall's own x-range. Diagnosis each time: read which sections/cut data actually existed before touching code.
- CS0165 out-params after short-circuited `&&`, again — pre-declare with defaults.
